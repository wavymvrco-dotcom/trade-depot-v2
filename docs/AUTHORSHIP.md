# Authorship

A dated record of human authorship for Trade Depot.

## Who designed what

- **Marco Lopez** conceived Trade Depot and the Autonomous Strategy Lab: the full loop
  (Blueprint → Gen Zero → Forge → Arena → Gauntlet → Vault Exam → Shadow Run → Live → Tripwire),
  the grading system (Licensed / Probation / Scrapped), the honesty rules, the product names,
  the Research Journal brand, and the phase plan. He wrote the build sheet that specifies them
  and makes the decisions recorded in `docs/DECISIONS.md`.

## How AI tools are used

- Claude Code (Anthropic) writes code to Marco's specification, proposes options, and flags
  conflicts between the spec and the code. Marco reviews and decides; commit messages describe
  the decision behind each change.
